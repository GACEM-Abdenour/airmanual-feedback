# AeroMind Feedback Dashboard - Quick Start Guide

Welcome to the AeroMind Feedback Dashboard. This tool helps you create exact examples of how the AI should answer questions to ensure high-quality, standardized responses.

## 1. Questions
- **Add a Question:** Click **Add New Question**. Fill in the Question, Expected Response, Key Points, and Expected Resources.
- **Edit a Question:** Click the **Pencil Icon** (✏️) on any question to update its contents.
- **Copy Content:** Hover over any text area and click the **Copy Icon** to instantly copy the text.

## 2. Global Rules & Categories
- **Global Settings:** Go to the **Global Rules** tab to define overarching instructions and safety redlines that apply to all answers.
- **Categories:** Create specific tags (e.g., *Tail Rotor Systems*) with their own unique rules. Assign these tags to questions to enforce specific formatting.

## 3. Collaboration
- **Reactions:** Use the **Thumbs Up/Down** (👍👎) buttons to rate the quality of an expected response.
- **Comments:** Use the comment section at the bottom of a question to discuss edge cases with your team.

## 4. Excel Export / Import
- **Export:** Click **Export Excel** to download your entire database as a spreadsheet.
- **Import:** You can write questions directly in Excel using the exported format. Click **Import Excel** to upload the spreadsheet and instantly update the dashboard.
